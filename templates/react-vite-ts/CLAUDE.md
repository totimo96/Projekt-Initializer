# Agent development rules
Before editing read docs/PROJECT.md, docs/ARCHITECTURE.md and docs/QUALITY.md. Normal feature requests require **no additional skill**. Define testable acceptance criteria, follow approved architecture, add suitable unit/component/E2E tests and run relevant checks. Before completion execute pnpm verify:full or explicitly report unavailable prerequisites. Never disable tests, lower quality thresholds or weaken CI to fake success. Document substantial changes. Report actual executed checks and outcomes. Never commit secrets or deploy without permission.
